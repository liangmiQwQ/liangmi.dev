# liangmi.dev

Source code of [liangmi.dev](https://liangmi.dev/), under development. Built on top of [Void](https://void.cloud/).

> [!IMPORTANT]
> This repo only includes the source code part, the information and articles are stored in other repositories.

If you also want to build your own website with similar features / style like [liangmi.dev](https://liangmi.dev/), you can modify the code and set a `.env` file like this.

```env
GITHUB_TOKEN=your_github_token
ARTICLE_REPO=your_username/your_article_repo
INFO_REPO=your_username/your_info_repo
```
